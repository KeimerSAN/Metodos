Método de bisección

El método más robusto para encontrar raíces: parte de un intervalo con cambio de signo y lo reduce a la mitad en cada paso hasta acorralar la solución.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Si f es continua en [a, b] y f(a) y f(b) tienen signos opuestos, el teorema del valor intermedio garantiza que existe al menos una raíz dentro del intervalo. El método de bisección aprovecha ese hecho: divide el intervalo por la mitad, conserva la mitad donde sigue habiendo cambio de signo, y repite el proceso hasta que el intervalo es tan pequeño como la tolerancia que definamos.

Es un método cerrado (de intervalo): no requiere derivadas ni una forma particular de la función, solo continuidad. A cambio, su velocidad de convergencia es lineal — más lenta que Muller o Newton-Raphson, pero prácticamente infalible si la condición inicial se cumple.

Como f(a)·f(c) < 0 en este ejemplo, la raíz queda acorralada en [a, c] y b se descarta — el intervalo se reduce a la mitad.

Algoritmo

  1. Elegir [a, b] tal que f(a) · f(b) < 0.
  2. Calcular el punto medio c = (a + b) / 2 y evaluar f(c).
  3. Si f(a) · f(c) < 0, la raíz está en [a, c] → hacer b = c.
  4. En caso contrario, la raíz está en [c, b] → hacer a = c.
  5. Repetir los pasos 2–4 hasta que |b − a| < ε o f(c) ≈ 0.

Ventajas, desventajas y cuándo usarlo

Ventajas

  • Convergencia garantizada si f(a)·f(b) < 0.
  • No necesita calcular derivadas.
  • Muy fácil de programar y de entender.
  • Es numéricamente estable, casi no acumula error de redondeo.

Desventajas

  • Convergencia lenta (lineal): reduce el error a la mitad en cada paso, no lo "acelera".
  • Necesitas encontrar primero un intervalo con cambio de signo.
  • No sirve para raíces de multiplicidad par (donde f no cambia de signo) ni para raíces complejas.

03

Circuitos

Hallar el punto de operación de un diodo o transistor cuando la curva característica no es lineal.

Errores comunes al aplicar bisección

  • No verificar f(a)·f(b) < 0 antes de empezar. Si no hay cambio de signo, el método puede converger a un valor que no es raíz, o simplemente fallar.
  • Confundir el criterio de parada. Detenerse cuando f(c) ≈ 0 no es lo mismo que detenerse cuando |b − a| es pequeño; a veces conviene usar ambos criterios juntos.
  • Elegir un intervalo demasiado grande. Si [a, b] contiene más de una raíz, el método solo encontrará una de ellas (no necesariamente la que buscas).

1. f(x) = cos(x) − x en el intervalo [0, 1]¿Ver ejercicio resuelto?

Paso 1 — Verificar el cambio de signo: f(0) = cos(0) − 0 = 1 (positivo). f(1) = cos(1) − 1 ≈ −0.4597 (negativo). Como cambian de signo, sí hay raíz en [0, 1].

Paso 2 — Iterar: se calcula c = (a+b)/2 y se evalúa f(c) en cada paso, igual que en los ejemplos de arriba, quedándose siempre con la mitad del intervalo donde sigue habiendo cambio de signo.

Paso 3 — Repetir hasta que el intervalo sea muy pequeño (por ejemplo, menor a 0.0001).

Respuesta: x ≈ 0.7391
2. f(x) = x² − 3 en el intervalo [1, 2] (equivale a aproximar √3)¿Ver ejercicio resuelto?

Paso 1: f(1) = 1 − 3 = −2, f(2) = 4 − 3 = 1 → cambio de signo, se puede aplicar bisección.

Paso 2: c₁ = 1.5 → f(1.5) = −0.75 (negativo) → como f(1)·f(1.5) > 0, el nuevo intervalo es [1.5, 2].

Paso 3: c₂ = 1.75 → f(1.75) = 0.0625 (positivo) → nuevo intervalo [1.5, 1.75].

Paso 4: el intervalo sigue reduciéndose a la mitad en cada paso hasta acercarse a √3.

Respuesta: x ≈ 1.7321 (√3)
3. f(x) = eˣ − 3x en el intervalo [0, 1]¿Ver ejercicio resuelto?

Paso 1: f(0) = 1 − 0 = 1, f(1) = e − 3 ≈ −0.2817 → cambio de signo, hay raíz en [0, 1].

Paso 2: se aplica el mismo procedimiento: punto medio, evaluar f(c), quedarse con la mitad correcta del intervalo, y repetir.

Paso 3: tras varias iteraciones el intervalo se estrecha alrededor de la raíz.

Respuesta: x ≈ 0.6191
4. f(x) = x³ − 4x − 9 en el intervalo [2, 3]¿Ver ejercicio resuelto?

Paso 1: f(2) = 8 − 8 − 9 = −9, f(3) = 27 − 12 − 9 = 6 → hay cambio de signo.
