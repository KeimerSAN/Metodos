¿Qué es un método numérico?

El punto de partida de todo el curso: por qué la ingeniería cambia la respuesta exacta por una aproximación con error controlado.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Un método numérico es un procedimiento sistemático, formado por un número finito de operaciones aritméticas y lógicas, que produce una aproximación a la solución de un problema matemático. No busca la respuesta exacta: busca una respuesta suficientemente buena, con un error que podamos acotar y controlar.

La necesidad aparece porque la inmensa mayoría de los problemas reales de ingeniería no tienen solución analítica cerrada. No existe fórmula para despejar x en cos(x) = x, ni para integrar e−x², ni para resolver un sistema de 10.000 ecuaciones a mano. El análisis numérico convierte esos problemas continuos en secuencias de cálculos que una computadora sí puede ejecutar.

La ecuación que resume todo el curso

Valor calculado = valor verdadero + error de truncamiento + error de redondeo. Todo el análisis numérico consiste en mantener esos dos errores bajo control mientras el algoritmo termina en un tiempo razonable.

El ciclo de trabajo de un método numérico

  1. Modelar: traducir el problema físico o de ingeniería a una ecuación matemática.
  2. Discretizar: reemplazar lo continuo (derivadas, integrales, límites) por operaciones finitas.
  3. Iterar: generar una sucesión de aproximaciones x₀, x₁, x₂, …
  4. Detener: aplicar un criterio de parada (tolerancia ε o máximo de iteraciones).
  5. Validar: estimar el error y comprobar que el resultado tiene sentido físico.
Criterio de parada por tolerancia

| xn+1 − xn | < ε

Criterio de parada por residuo

| f(xn) | < ε

Error relativo aproximado

εr = | (xn+1 − xn) / xn+1 |

Ventajas y desventajas

Ventajas

  • Resuelven problemas que no tienen solución analítica.
  • Se programan una sola vez y se reutilizan con cualquier dato.
  • Permiten estimar y acotar el error cometido.
  • Escalan a problemas con miles o millones de incógnitas.

Desventajas

  • El resultado siempre es aproximado, nunca exacto.
  • Acumulan errores de redondeo por la aritmética finita del computador.
  • Algunos métodos divergen si los valores iniciales son malos.
  • Requieren analizar la estabilidad: un método válido en teoría puede ser inútil en la práctica.

Errores comunes

  • Confundir aproximado con incorrecto. Un resultado con error menor que la tolerancia es perfectamente válido en ingeniería; lo incorrecto es no saber cuánto error tiene.
  • Olvidar el máximo de iteraciones. Sin un tope, un método que diverge deja el programa en un bucle infinito.
  • Comparar números reales con igualdad. Escribir if x == 0.7 casi nunca se cumple en punto flotante; hay que comparar contra una tolerancia.

Banco de ejercicios propuestos

Intenta resolver cada punto antes de abrir la solución.

1. Clasifica: ¿cuáles de estas ecuaciones necesitan un método numérico? (a) 3x − 7 = 0, (b) x² − 5x + 6 = 0, (c) ex = 3x, (d) x⁵ − x − 1 = 0¿Ver ejercicio resuelto?

(a) Analítica: x = 7/3.

(b) Analítica: fórmula cuadrática → x = 2 y x = 3.

(c) Numérica: mezcla una exponencial con un polinomio, no hay despeje posible.

(d) Numérica: por el teorema de Abel-Ruffini, los polinomios de grado 5 no tienen fórmula general por radicales.

Respuesta: Necesitan método numérico las opciones (c) y (d).
2. Aplica xn+1 = cos(xn) desde x₀ = 0.5 y realiza 4 iteraciones.¿Ver ejercicio resuelto?

x₁ = cos(0.5) = 0.877583

x₂ = cos(0.877583) = 0.639012

x₃ = cos(0.639012) = 0.802685

x₄ = cos(0.802685) = 0.694778

La sucesión oscila alrededor de 0.739085 y se va cerrando sobre ese valor.

Respuesta: x₄ ≈ 0.694778, acercándose a x* ≈ 0.739085.
3. ¿Cuántas iteraciones necesita un método que reduce el error a la mitad en cada paso para pasar de un error de 1 a un error menor que 10−3?¿Ver ejercicio resuelto?

El error tras n pasos es 1/2n.

Se busca 1/2n < 10−3, es decir 2n > 1000.

Como 29 = 512 y 210 = 1024, se necesita n = 10.

Respuesta: 10 iteraciones.
