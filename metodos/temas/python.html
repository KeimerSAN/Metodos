Idea central

Python se ha convertido en el lenguaje estándar para enseñar y aplicar métodos numéricos: la sintaxis se parece al pseudocódigo, los float son de doble precisión por defecto y las bibliotecas NumPy, SciPy y Matplotlib cubren desde el álgebra lineal hasta la graficación.

Lo mínimo del lenguaje

Sintaxis esencial para el curso
import math

# 1. Definir una funcion matematica
def f(x):
    return x**3 - x - 2

# 2. Definir su derivada (necesaria para Newton)
def df(x):
    return 3*x**2 - 1

# 3. Bucle con criterio de parada por tolerancia
x, tol, max_iter = 1.5, 1e-10, 100
for i in range(max_iter):
    x_nuevo = x - f(x) / df(x)
    if abs(x_nuevo - x) < tol:      # nunca usar == con flotantes
        break
    x = x_nuevo

print(f"Raiz = {x_nuevo:.10f} en {i+1} iteraciones")

# 4. Funciones anonimas (lambda) para pasar f como argumento
g = lambda x: math.cos(x)
print(g(0))            # 1.0

Ejercicio resuelto: bisección completa en Python

Implementación con validación de la condición inicial, tolerancia, máximo de iteraciones y tabla de salida.

biseccion.py
def biseccion(f, a, b, tol=1e-8, max_iter=100, verbose=True):
    """Devuelve una raiz de f en [a, b] por el metodo de biseccion."""
    fa, fb = f(a), f(b)
    if fa * fb > 0:
        raise ValueError("No hay cambio de signo en [a, b]: f(a)*f(b) > 0")

    if verbose:
        print(f"{'i':>3} {'a':>12} {'b':>12} {'c':>12} {'f(c)':>14}")

    c = a
    for i in range(1, max_iter + 1):
        c = (a + b) / 2
        fc = f(c)
        if verbose:
            print(f"{i:>3} {a:>12.6f} {b:>12.6f} {c:>12.6f} {fc:>14.6e}")

        if fc == 0 or (b - a) / 2 < tol:      # criterio de parada
            return c, i

        if fa * fc < 0:
            b, fb = c, fc
        else:
            a, fa = c, fc

    raise RuntimeError(f"No convergio en {max_iter} iteraciones")


if __name__ == "__main__":
    f = lambda x: x**3 - x - 2
    raiz, iteraciones = biseccion(f, 1, 2, tol=1e-10)
    print(f"\nRaiz = {raiz:.10f}  ({iteraciones} iteraciones)")

Salida: Raiz = 1.5213797068 (34 iteraciones). La bisección necesita muchas iteraciones porque su convergencia es lineal.

Vectorización con NumPy

NumPy permite evaluar una función sobre miles de puntos sin escribir un bucle, lo que es mucho más rápido y más legible:

Tabular y graficar una función
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-2, 3, 500)      # 500 puntos entre -2 y 3
y = x**3 - x - 2                 # se evalua sobre todo el arreglo de una vez

plt.axhline(0, color="#5A6866", linewidth=1)
plt.plot(x, y, color="#0F6E73", linewidth=2, label="f(x) = x^3 - x - 2")
plt.plot(1.5213797, 0, "o", color="#BB4F27", markersize=9, label="raiz")
plt.legend(); plt.grid(alpha=.3)
plt.title("Localizacion grafica de la raiz")
plt.savefig("raiz.png", dpi=150)

# Deteccion automatica de cambios de signo (localizacion de raices)
signos = np.sign(y)
cambios = np.where(np.diff(signos) != 0)[0]
print("Intervalos con raiz:", [(x[i], x[i+1]) for i in cambios])

Atajo: SciPy ya lo trae hecho

Para trabajo real no se reimplementan los métodos: scipy.optimize.brentq(f, a, b) halla raíces, scipy.integrate.solve_ivp resuelve EDO y numpy.linalg.solve resuelve sistemas lineales. Programarlos a mano es un ejercicio de aprendizaje: sirve para entender el error y la convergencia.

Ventajas y desventajas

Ventajas

  • Sintaxis cercana al pseudocódigo: el método se lee tal como se explica en clase.
  • Doble precisión IEEE 754 por defecto en todos los float.
  • Ecosistema numérico maduro, libre y multiplataforma.
  • Gráficas inmediatas con Matplotlib para visualizar convergencia.

Desventajas

  • Los bucles puros en Python son lentos: hay que vectorizar con NumPy.
  • No es tipado estático, así que ciertos errores solo aparecen en ejecución.
  • Requiere instalar dependencias externas para lo más interesante.

Errores comunes

  • Usar == entre flotantes. Siempre abs(a - b) < tol; en NumPy, np.isclose(a, b).
  • Escribir ^ para potencia. En Python ^ es XOR de bits. La potencia es **: x**2.
  • Olvidar el max_iter. Un while sin tope deja el programa colgado cuando el método diverge.
  • Dividir enteros esperando un real. En Python 3 / siempre devuelve float, pero // trunca: 7//2 da 3, no 3.5.
