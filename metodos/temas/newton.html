Método de Newton-Raphson

El método más rápido del curso: sigue la recta tangente hasta el eje x y duplica las cifras correctas en cada iteración.

En esta página

Practicar este tema Ver los 16 temas

Idea central

El método de Newton-Raphson aproxima la función por su recta tangente en el punto actual y toma como siguiente aproximación el punto donde esa tangente corta el eje x. Geométricamente: si la curva es suave, su tangente apunta hacia la raíz.

Es el método más rápido del curso — convergencia cuadrática, duplica las cifras correctas en cada paso — pero también el más exigente: necesita la derivada y puede divergir si el punto inicial está mal elegido.

Deducción desde la tangente

0 = f(xn) + f′(xn)(xn+1 − xn)

Fórmula de Newton-Raphson

xn+1 = xn − f(xn) / f′(xn)

Error asintótico

en+1 ≈ | f″(x*) / (2 f′(x*)) | · en2

La tangente trazada en x₀ corta el eje en x₁, mucho más cerca de la raíz x* que el punto de partida. Repitiendo el trazo, el error se eleva al cuadrado en cada paso.

Algoritmo

  1. Elegir un valor inicial x₀ razonablemente cerca de la raíz (una gráfica previa ayuda mucho).
  2. Evaluar f(xn) y f′(xn).
  3. Verificar que f′(xn) ≠ 0; si es cero o casi cero, detener y cambiar de x₀.
  4. Calcular xn+1 = xn − f(xn)/f′(xn).
  5. Repetir hasta que |xn+1 − xn| < ε o se agote el máximo de iteraciones.

Implementación en Python con todas las validaciones
def newton(f, df, x0, tol=1e-12, max_iter=50):
    """Metodo de Newton-Raphson con control de derivada nula."""
    x = x0
    for i in range(1, max_iter + 1):
        fx, dfx = f(x), df(x)
        if abs(dfx) < 1e-14:
            raise ZeroDivisionError(f"Derivada casi nula en x = {x}")
        x_nuevo = x - fx / dfx
        if abs(x_nuevo - x) < tol:
            return x_nuevo, i
        x = x_nuevo
    raise RuntimeError(f"No convergio en {max_iter} iteraciones")


f  = lambda x: x**3 - x - 2
df = lambda x: 3*x**2 - 1
raiz, n = newton(f, df, 1.5)
print(f"Raiz = {raiz:.12f} en {n} iteraciones")
# Raiz = 1.521379706805 en 5 iteraciones

Cuando no tienes la derivada: el método de la secante

Si f′ es difícil o imposible de obtener, se reemplaza por una diferencia dividida entre los dos últimos puntos: xn+1 = xn − f(xn)(xn − xn−1) / (f(xn) − f(xn−1)). Se pierde algo de velocidad (orden 1.618 en vez de 2) pero se ahorra una evaluación por paso.

Casos en los que Newton falla

SituaciónQué ocurreSolución práctica
f′(xn) = 0División entre cero: el método se detieneCambiar el punto inicial
Raíz múltipleLa convergencia baja de orden 2 a orden 1Usar la variante x − m·f/f′ con m la multiplicidad
x₀ lejanoPuede saltar a otra raíz o divergirLocalizar gráficamente o iniciar con bisección
Punto de inflexión cercanoLa sucesión entra en un ciclo x₀ → x₁ → x₀Amortiguar el paso o cambiar de método

Ventajas y desventajas

Ventajas

  • Convergencia cuadrática: duplica las cifras correctas en cada iteración.
  • Muy pocas iteraciones cuando x₀ está cerca de la raíz.
  • Se extiende sin cambios a sistemas de ecuaciones no lineales usando la matriz jacobiana.
  • Es la base de casi todos los optimizadores modernos.

Desventajas

  • Requiere conocer y evaluar f′(x) en cada paso.
  • Falla si f′(xn) se anula o es muy pequeña.
  • La convergencia solo está garantizada localmente: un mal x₀ puede divergir.
  • Pierde su orden 2 en raíces múltiples.

Errores comunes

  • No verificar que f′(xn) ≠ 0. Sin esa comprobación el programa lanza una división entre cero o produce un salto enorme.
  • Elegir x₀ al azar. Graficar la función o hacer una tabla de signos antes cuesta poco y evita la divergencia.
  • Derivar mal f′(x). Un error en la derivada casi siempre se manifiesta como convergencia lineal en lugar de cuadrática: es la señal de alerta.
  • Usar Newton en una raíz múltiple sin ajustar. Con multiplicidad m, la fórmula modificada x − m·f/f′ recupera el orden 2.

Banco de ejercicios propuestos

Aplica la fórmula xn+1 = xn − f(xn)/f′(xn) paso a paso.

1. f(x) = x² − 2 desde x₀ = 1 (aproximar √2).¿Ver ejercicio resuelto?

f′(x) = 2x, luego xn+1 = xn − (xn²−2)/(2xn) = (xn + 2/xn)/2.

x₁ = (1 + 2)/2 = 1.5

x₂ = (1.5 + 2/1.5)/2 = 1.4166666667

x₃ = 1.4142156863

x₄ = 1.4142135624

Esta es la fórmula babilónica de la raíz cuadrada, conocida milenios antes que Newton.

Respuesta: x* ≈ 1.4142135624 en 4 iteraciones.
2. f(x) = ex − 3x desde x₀ = 0.5.¿Ver ejercicio resuelto?

f′(x) = ex − 3.

f(0.5) = 1.648721 − 1.5 = 0.148721; f′(0.5) = 1.648721 − 3 = −1.351279.

x₁ = 0.5 + 0.148721/1.351279 = 0.610057

x₂ = 0.618962; x₃ = 0.619061

Nota: esta función tiene dos raíces; con x₀ = 1.5 se converge a la otra, x ≈ 1.5121.

Respuesta: x* ≈ 0.6190612867
3. f(x) = x³ − 2x − 5 desde x₀ = 2 (el ejemplo original de Newton).¿Ver ejercicio resuelto?

f′(x) = 3x² − 2.

f(2) = 8 − 4 − 5 = −1; f′(2) = 10.

x₁ = 2 + 1/10 = 2.1

x₂ = 2.0945681211; x₃ = 2.0945514815

Newton publicó este mismo ejemplo en 1669.

Respuesta: x* ≈ 2.0945514815
4. ¿Qué pasa al aplicar Newton a f(x) = x³ desde x₀ = 1? La raíz x = 0 es triple.¿Ver ejercicio resuelto?

f′(x) = 3x², luego xn+1 = xn − xn³/(3xn²) = (2/3)xn.

La sucesión es 1, 0.6667, 0.4444, 0.2963, …: cada error es 2/3 del anterior.

Eso es convergencia lineal con λ = 2/3, no cuadrática.

La fórmula corregida xn+1 = xn − 3·f/f′ da x₁ = 0 en un solo paso.

Respuesta: Converge, pero solo linealmente: es el efecto de la raíz múltiple.
5. Deduce la fórmula de Newton a partir del desarrollo de Taylor de primer orden.¿Ver ejercicio resuelto?

Se desarrolla f alrededor de xn: f(x) ≈ f(xn) + f′(xn)(x − xn).

Se busca el x que anula esa aproximación lineal: 0 = f(xn) + f′(xn)(x − xn).

Despejando: x = xn − f(xn)/f′(xn).

El término descartado es (f″/2)(x−xn)², y de ahí sale precisamente el error cuadrático.

Respuesta: xn+1 = xn − f(xn)/f′(xn), truncando Taylor en el término lineal.
