Método de Runge-Kutta

Orden 4 sin derivar nada: cuatro evaluaciones bien colocadas dentro del intervalo y un promedio ponderado de pendientes.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Los métodos de Runge-Kutta resuelven el gran inconveniente del método de Taylor: alcanzan un orden alto sin necesidad de calcular derivadas. En lugar de derivar f, la evalúan varias veces dentro del intervalo [tn, tn+h] y combinan esas pendientes con pesos cuidadosamente elegidos.

El más usado es el Runge-Kutta clásico de cuarto orden (RK4): cuatro evaluaciones de f por paso y un error global O(h⁴). Es el caballo de batalla de la simulación numérica desde hace un siglo.

El problema de valor inicial que usaremos en toda la unidad

y′ = y − t² + 1, con y(0) = 0.5 en el intervalo [0, 2] y paso h = 0.2. Su solución exacta es y(t) = (t + 1)² − ½et, así que podemos comparar el error real de cada método sobre exactamente el mismo problema.

Pendiente al inicio del intervalo

k₁ = h · f(tn, yn)

Pendiente en el punto medio (1)

k₂ = h · f(tn + h/2, yn + k₁/2)

Pendiente en el punto medio (2)

k₃ = h · f(tn + h/2, yn + k₂/2)

Pendiente al final del intervalo

k₄ = h · f(tn + h, yn + k₃)

Combinación ponderada

yn+1 = yn + (k₁ + 2k₂ + 2k₃ + k₄) / 6

¿Por qué esos pesos 1, 2, 2, 1?

Los coeficientes se obtienen igualando el desarrollo de la combinación con la serie de Taylor de y(t+h) hasta el término h⁴. Las pendientes del punto medio pesan el doble porque son las que mejor representan el comportamiento promedio en el intervalo. La suma de pesos es 1/6 + 2/6 + 2/6 + 1/6 = 1, es decir, es un promedio ponderado de pendientes.

La familia Runge-Kutta

MétodoEtapas (evaluaciones de f)Error globalObservación
RK1 (Euler)1O(h)El caso más simple de la familia
RK2 (Euler mejorado / Heun)2O(h²)Promedia la pendiente inicial y la final
RK2 (punto medio)2O(h²)Usa solo la pendiente del centro
RK33O(h³)Poco usado en la práctica
RK4 clásico4O(h⁴)El estándar de facto
RK45 (Dormand-Prince)6O(h⁵) con estimadorPaso adaptativo; es el que usa SciPy

A partir de orden 5 el número de etapas crece más rápido que el orden, por eso RK4 es el punto óptimo entre costo y precisión.

Algoritmo (RK4)

  1. Definir f(t, y), la condición inicial (t₀, y₀), el paso h y el número de pasos N.
  2. Calcular k₁ usando la pendiente al inicio del intervalo.
  3. Calcular k₂ y k₃ usando dos estimaciones sucesivas de la pendiente en el punto medio.
  4. Calcular k₄ usando la pendiente al final, estimada con k₃.
  5. Combinar: yn+1 = yn + (k₁ + 2k₂ + 2k₃ + k₄)/6.
  6. Avanzar tn+1 = tn + h y repetir hasta cubrir el intervalo.

RK4 en Python
import math

def rk4(f, t0, y0, h, n):
    """Runge-Kutta clasico de cuarto orden."""
    ts, ys = [t0], [y0]
    t, y = t0, y0
    for _ in range(n):
        k1 = h * f(t,         y)
        k2 = h * f(t + h/2,   y + k1/2)
        k3 = h * f(t + h/2,   y + k2/2)
        k4 = h * f(t + h,     y + k3)
        y = y + (k1 + 2*k2 + 2*k3 + k4) / 6
        t = t + h
        ts.append(t)
        ys.append(y)
    return ts, ys


f = lambda t, y: y - t**2 + 1
exacta = lambda t: (t + 1)**2 - 0.5 * math.exp(t)

ts, ys = rk4(f, 0.0, 0.5, 0.2, 10)
for t, y in zip(ts, ys):
    print(f"{t:.1f}  {y:.7f}  error={abs(exacta(t)-y):.2e}")

Ventajas y desventajas

Ventajas

  • Orden 4 sin calcular ni una sola derivada de f.
  • Código totalmente genérico: la misma función sirve para cualquier EDO.
  • Es autoiniciable: solo necesita el valor anterior, no un historial.
  • Permite cambiar el paso h en cualquier momento sin complicaciones.
  • Muy estable para la mayoría de problemas no rígidos.

Desventajas

  • Cuatro evaluaciones de f por paso: si f es cara, el costo se nota.
  • No proporciona por sí solo una estimación del error (para eso existen los pares encajados como RK45).
  • No es adecuado para problemas rígidos (stiff), donde se necesitan métodos implícitos.
  • Desaprovecha información: descarta todas las evaluaciones de los pasos anteriores.

Errores comunes

  • Olvidar multiplicar por h en las k. Si defines k₁ = f(…) en lugar de h·f(…), debes dividir distinto al combinar; mezclar las dos convenciones es el error más común.
  • Evaluar k₃ con k₁ en vez de k₂. Cada etapa usa la anterior; romper esa cadena degrada silenciosamente el orden de 4 a 2.
  • Usar t + h/2 en k₄. La cuarta etapa se evalúa en el extremo derecho, t + h, no en el punto medio.
  • Aplicar RK4 a un problema rígido. Con ecuaciones stiff, RK4 obliga a un h minúsculo; ahí se usan métodos implícitos como BDF o Radau.

Banco de ejercicios propuestos

Calcula las cuatro pendientes ordenadamente antes de combinarlas.

1. y′ = y, y(0) = 1, h = 0.5. Da un paso de RK4 y compara con e0.5.¿Ver ejercicio resuelto?

k₁ = 0.5 · f(0, 1) = 0.5 · 1 = 0.5

k₂ = 0.5 · f(0.25, 1 + 0.25) = 0.5 · 1.25 = 0.625

k₃ = 0.5 · f(0.25, 1 + 0.3125) = 0.5 · 1.3125 = 0.65625

k₄ = 0.5 · f(0.5, 1 + 0.65625) = 0.5 · 1.65625 = 0.828125

y₁ = 1 + (0.5 + 1.25 + 1.3125 + 0.828125)/6 = 1 + 0.6484375 = 1.6484375

Valor exacto: e0.5 = 1.6487213.

Respuesta: y₁ = 1.6484375 frente a 1.6487213: error de solo 2.8 × 10−4 en un único paso.
2. y′ = t + y, y(0) = 1, h = 0.2. Da un paso de RK4.¿Ver ejercicio resuelto?

k₁ = 0.2 · (0 + 1) = 0.2

k₂ = 0.2 · (0.1 + 1.1) = 0.24

k₃ = 0.2 · (0.1 + 1.12) = 0.244

k₄ = 0.2 · (0.2 + 1.244) = 0.2888

y₁ = 1 + (0.2 + 0.48 + 0.488 + 0.2888)/6 = 1 + 0.2428 = 1.2428

Exacto: y(0.2) = 2e0.2 − 1.2 = 1.2428055.

Respuesta: y₁ = 1.2428000, con un error de 5.5 × 10−6.
3. Si con h = 0.2 el error de RK4 es 2 × 10−6, ¿cuánto será con h = 0.1?¿Ver ejercicio resuelto?

El error global de RK4 es O(h⁴).

Al dividir h entre 2, el error se divide entre 2⁴ = 16.

2 × 10−6 / 16 = 1.25 × 10−7.

Respuesta: Aproximadamente 1.25 × 10−7.
4. Escribe el método de Heun (RK2) y aplica un paso a y′ = y − t² + 1, y(0) = 0.5, h = 0.2.¿Ver ejercicio resuelto?

Heun: k₁ = h·f(tn, yn), k₂ = h·f(tn+h, yn+k₁), yn+1 = yn + (k₁ + k₂)/2.

k₁ = 0.2 · (0.5 − 0 + 1) = 0.3

k₂ = 0.2 · (0.8 − 0.04 + 1) = 0.2 · 1.76 = 0.352

y₁ = 0.5 + (0.3 + 0.352)/2 = 0.5 + 0.326 = 0.826

Exacto: y(0.2) = 0.8292986. Euler daba 0.8 y RK4 da 0.8292933.

Respuesta: y₁ = 0.826, con error 3.3 × 10−3: entre Euler y RK4, como corresponde a un método de orden 2.
