El método de Euler

El primer paso en la solución numérica de ecuaciones diferenciales: avanzar siguiendo la tangente y aceptar un error de primer orden.

En esta página

Practicar este tema Ver los 16 temas

Idea central

El método de Euler es el punto de partida de toda la integración numérica de ecuaciones diferenciales. Parte de una idea muy simple: si conozco el valor de y en tn y conozco su pendiente y′ = f(t, y), puedo avanzar un paso pequeño h siguiendo esa recta tangente.

Es el equivalente, en el mundo de las EDO, de truncar la serie de Taylor en el primer término. Por eso su error local es O(h²) y su error global O(h): es un método de primer orden.

El problema de valor inicial que usaremos en toda la unidad

y′ = y − t² + 1, con y(0) = 0.5 en el intervalo [0, 2] y paso h = 0.2. Su solución exacta es y(t) = (t + 1)² − ½et, así que podemos comparar el error real de cada método sobre exactamente el mismo problema.

Problema de valor inicial

y′ = f(t, y),   y(t₀) = y₀

Fórmula de Euler hacia adelante

yn+1 = yn + h · f(tn, yn)

Avance del tiempo

tn+1 = tn + h

Error local / global

O(h²) por paso  →  O(h) acumulado

Euler reemplaza la curva por una poligonal de segmentos tangentes. Cada paso introduce un error pequeño, pero esos errores se acumulan: por eso la poligonal se aleja más de la curva a medida que avanza t.

Algoritmo

  1. Definir f(t, y), la condición inicial (t₀, y₀), el intervalo [a, b] y el número de pasos N.
  2. Calcular el tamaño de paso h = (b − a) / N.
  3. Para n = 0, 1, …, N−1: evaluar la pendiente f(tn, yn).
  4. Avanzar: yn+1 = yn + h · f(tn, yn) y tn+1 = tn + h.
  5. Repetir hasta llegar a t = b.

Implementación en Python
import math

def euler(f, t0, y0, h, n):
    """Resuelve y' = f(t, y) con y(t0) = y0 dando n pasos de tamano h."""
    ts, ys = [t0], [y0]
    t, y = t0, y0
    for _ in range(n):
        y = y + h * f(t, y)      # avanzar siguiendo la tangente
        t = t + h
        ts.append(t)
        ys.append(y)
    return ts, ys


f = lambda t, y: y - t**2 + 1
exacta = lambda t: (t + 1)**2 - 0.5 * math.exp(t)

ts, ys = euler(f, 0.0, 0.5, 0.2, 10)
print(f"{'t':>5} {'Euler':>12} {'Exacta':>12} {'Error':>12}")
for t, y in zip(ts, ys):
    print(f"{t:>5.1f} {y:>12.7f} {exacta(t):>12.7f} {abs(exacta(t)-y):>12.7f}")

Ventajas y desventajas

Ventajas

  • Es el método más simple de entender y de programar: una sola línea por paso.
  • Solo requiere una evaluación de f por paso, así que cada paso es muy barato.
  • Sirve como base conceptual de todos los métodos posteriores (Taylor, Runge-Kutta, multipaso).
  • Su versión implícita (Euler hacia atrás) es incondicionalmente estable para problemas rígidos.

Desventajas

  • Solo tiene orden 1: para ganar una cifra hay que dividir h entre 10.
  • El error se acumula paso a paso y crece a lo largo del intervalo.
  • Puede volverse inestable si h es grande frente a la escala del problema.
  • En la práctica casi nunca se usa para producción: se prefiere Runge-Kutta.

Errores comunes

  • Usar un h demasiado grande. Si h supera la escala característica del problema, la solución numérica puede oscilar o divergir aunque la exacta sea suave.
  • Evaluar f en el punto equivocado. Euler explícito usa f(tn, yn), no f(tn+1, yn+1): esa confusión produce el método implícito, que necesita resolver una ecuación en cada paso.
  • Actualizar t antes que y. Si se incrementa t primero, la pendiente se evalúa en el instante equivocado y el método pierde incluso su orden 1.
  • Confundir error local con error global. El error local es O(h²), pero como hay N = (b−a)/h pasos, el error global acumulado queda en O(h).

Banco de ejercicios propuestos

Aplica yn+1 = yn + h·f(tn, yn) paso a paso.

1. y′ = t + y, y(0) = 1, h = 0.1. Calcula y₁, y₂ e y₃.¿Ver ejercicio resuelto?

y₁ = 1 + 0.1(0 + 1) = 1.1

y₂ = 1.1 + 0.1(0.1 + 1.1) = 1.1 + 0.12 = 1.22

y₃ = 1.22 + 0.1(0.2 + 1.22) = 1.22 + 0.142 = 1.362

La solución exacta es y(t) = 2et − t − 1; en t = 0.3 vale 1.399718.

Respuesta: y₁ = 1.1, y₂ = 1.22, y₃ = 1.362 (error en t = 0.3: 0.0377).
2. y′ = −2y, y(0) = 1, h = 0.5. ¿Qué ocurre?¿Ver ejercicio resuelto?

yn+1 = yn + 0.5(−2yn) = yn(1 − 1) = 0.

El método colapsa a cero en un solo paso, cuando la solución exacta e−2t decae suavemente.

Con h = 1.0 el factor sería (1 − 2) = −1 y la solución oscilaría entre 1 y −1 sin decaer nunca.

La condición de estabilidad es |1 + hλ| < 1, es decir h < 2/|λ| = 1.

Respuesta: Con h = 0.5 el resultado se anula de golpe; con h ≥ 1 el método es inestable y oscila.
3. y′ = y, y(0) = 1, h = 0.25. Calcula y(1) y compara con e.¿Ver ejercicio resuelto?

Cada paso multiplica por (1 + h) = 1.25.

Tras 4 pasos: y₄ = 1.25⁴ = 2.441406.

El valor exacto es e = 2.718282.

Error absoluto: 0.276876, es decir 10.2 % de error relativo.

Respuesta: y(1) ≈ 2.4414 frente a e = 2.7183 — un 10 % de error.
4. ¿Cuántos pasos necesita Euler para bajar el error de 0.1 a 0.001 en un mismo intervalo?¿Ver ejercicio resuelto?

El error global es O(h), así que para dividir el error entre 100 hay que dividir h entre 100.

Si h se divide entre 100, el número de pasos se multiplica por 100.

Ese costo es justamente la razón por la que se prefieren métodos de orden superior como Runge-Kutta.

Respuesta: Cien veces más pasos; con un método O(h⁴) bastaría con multiplicarlos por 3.2.
