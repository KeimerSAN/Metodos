Métodos multipaso

Reutilizar el historial en vez de tirarlo: orden 4 con la mitad de evaluaciones que Runge-Kutta, a cambio de necesitar un arranque.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Euler, Taylor y Runge-Kutta son métodos de un paso: para calcular yn+1 solo usan yn y tiran a la basura todo lo calculado antes. Los métodos multipaso hacen lo contrario: aprovechan el historial yn, yn−1, yn−2, … y sus pendientes ya evaluadas.

El resultado es un método de orden 4 que necesita una sola evaluación nueva de f por paso, frente a las cuatro de RK4. El precio: hay que arrancar con otro método y el paso h no se cambia fácilmente.

El problema de valor inicial que usaremos en toda la unidad

y′ = y − t² + 1, con y(0) = 0.5 en el intervalo [0, 2] y paso h = 0.2. Su solución exacta es y(t) = (t + 1)² − ½et, así que podemos comparar el error real de cada método sobre exactamente el mismo problema.

Predictor y corrector

Los métodos multipaso se dividen en dos familias que se usan en pareja:

FamiliaTipoFórmula de 4 pasosPapel
Adams-BashforthExplícitoyn+1 = yn + (h/24)(55fn − 59fn−1 + 37fn−2 − 9fn−3)Predictor: estima yn+1
Adams-MoultonImplícitoyn+1 = yn + (h/24)(9fn+1 + 19fn − 5fn−1 + fn−2)Corrector: refina la estimación

Adams-Moulton es implícito porque fn+1 depende de yn+1, el valor que se busca. La solución práctica es usar el predictor para estimarlo y luego corregir: es el esquema PECE (Predice, Evalúa, Corrige, Evalúa).

Adams-Bashforth de 2 pasos

yn+1 = yn + (h/2)(3fn − fn−1)

Adams-Bashforth de 4 pasos

yn+1 = yn + (h/24)(55fn − 59fn−1 + 37fn−2 − 9fn−3)

Adams-Moulton de 3 pasos

yn+1 = yn + (h/24)(9fn+1 + 19fn − 5fn−1 + fn−2)

Estimación del error local

|ycorr − ypred| · 19/270

El problema del arranque

Un método de 4 pasos necesita y₀, y₁, y₂, y₃ para dar el primer paso, pero la condición inicial solo aporta y₀. La solución estándar es arrancar con RK4, que es autoiniciable y del mismo orden, y cambiar a multipaso a partir de ahí.

Algoritmo (predictor-corrector de cuarto orden)

  1. Arranque: calcular y₁, y₂, y₃ con Runge-Kutta de cuarto orden.
  2. Predice (P): aplicar Adams-Bashforth de 4 pasos para obtener una estimación y*n+1.
  3. Evalúa (E): calcular f(tn+1, y*n+1).
  4. Corrige (C): aplicar Adams-Moulton de 3 pasos usando esa evaluación.
  5. Evalúa (E): recalcular f con el valor corregido, listo para el siguiente paso.
  6. Estimar el error local con la diferencia entre predictor y corrector; si es excesivo, reducir h y reiniciar el arranque.

Métodos de un paso frente a multipaso

AspectoUn paso (RK4)Multipaso (Adams orden 4)
Evaluaciones de f por paso42 (predictor + corrector)
¿Necesita arranque?No, es autoiniciableSí, requiere 4 valores previos
¿Cambiar h es sencillo?Sí, en cualquier momentoNo, obliga a reiniciar el arranque

Cuándo convieneUso general, f barata, paso variableIntervalos largos con f cara y paso fijo

Regla práctica: si evaluar f es caro y el intervalo es largo, los multipaso ganan; si f es barata o hace falta paso adaptativo, gana Runge-Kutta.

Predictor-corrector de cuarto orden en Python
import math

def rk4_paso(f, t, y, h):
    k1 = h * f(t,       y)
    k2 = h * f(t + h/2, y + k1/2)
    k3 = h * f(t + h/2, y + k2/2)
    k4 = h * f(t + h,   y + k3)
    return y + (k1 + 2*k2 + 2*k3 + k4) / 6


def adams_pece(f, t0, y0, h, n):
    """Adams-Bashforth 4 (predictor) + Adams-Moulton 3 (corrector)."""
    ts, ys = [t0], [y0]
    # 1. Arranque con RK4: hacen falta 4 valores
    for _ in range(3):
        ys.append(rk4_paso(f, ts[-1], ys[-1], h))
        ts.append(ts[-1] + h)

    # 2. Bucle predictor-corrector
    for i in range(3, n):
        f0 = f(ts[i],   ys[i])       # f_n
        f1 = f(ts[i-1], ys[i-1])     # f_{n-1}
        f2 = f(ts[i-2], ys[i-2])     # f_{n-2}
        f3 = f(ts[i-3], ys[i-3])     # f_{n-3}
        t_next = ts[i] + h

        # P: predictor explicito (Adams-Bashforth)
        yp = ys[i] + h/24 * (55*f0 - 59*f1 + 37*f2 - 9*f3)
        # E: evaluar en el punto predicho
        fp = f(t_next, yp)
        # C: corrector implicito (Adams-Moulton)
        yc = ys[i] + h/24 * (9*fp + 19*f0 - 5*f1 + f2)

        error_estimado = abs(yc - yp) * 19/270    # gratis
        ts.append(t_next)
        ys.append(yc)
    return ts, ys


f = lambda t, y: y - t**2 + 1
exacta = lambda t: (t + 1)**2 - 0.5 * math.exp(t)
ts, ys = adams_pece(f, 0.0, 0.5, 0.2, 10)
for t, y in zip(ts, ys):
    print(f"{t:.1f}  {y:.7f}  error={abs(exacta(t)-y):.2e}")

Ventajas y desventajas

Ventajas

  • Solo una o dos evaluaciones nuevas de f por paso, frente a las cuatro de RK4.
  • Muy eficiente cuando evaluar f es costoso y el intervalo es largo.
  • La diferencia predictor-corrector da una estimación del error sin costo adicional.
  • Los correctores implícitos (Adams-Moulton, BDF) tienen mejores propiedades de estabilidad.

Desventajas

  • No son autoiniciables: hay que arrancar con un método de un paso.
  • Cambiar el tamaño de paso obliga a repetir el arranque o a interpolar el historial.
  • Necesitan almacenar el historial de pendientes.
  • Son menos estables que RK4 si el paso se elige mal, y hay fórmulas multipaso directamente inestables.

Errores comunes

  • Arrancar el multipaso con Euler. Si los valores de arranque tienen error O(h), contaminan todo el cálculo y el método nunca alcanza su orden 4. Hay que arrancar con RK4.
  • Confundir el orden de los índices. En Adams-Bashforth, el coeficiente 55 acompaña a fn (el más reciente) y −9 a fn−3 (el más antiguo). Invertirlos destruye el resultado.
  • Cambiar h a mitad de camino. El historial guardado corresponde al paso anterior; cambiar h sin reiniciar el arranque introduce un error grande.
  • Iterar el corrector muchas veces. Con una sola corrección basta. Iterar hasta convergencia gasta evaluaciones y elimina justamente la ventaja del método.

Banco de ejercicios propuestos

Ten a mano las fórmulas de Adams-Bashforth y Adams-Moulton.

1. Aplica Adams-Bashforth de 2 pasos a y′ = y, con y₀ = 1, y₁ = 1.105171 (h = 0.1). Calcula y₂.¿Ver ejercicio resuelto?

f₁ = y₁ = 1.105171; f₀ = y₀ = 1.

y₂ = y₁ + (h/2)(3f₁ − f₀) = 1.105171 + 0.05(3·1.105171 − 1)

= 1.105171 + 0.05(3.315513 − 1) = 1.105171 + 0.115776 = 1.220947

Valor exacto: e0.2 = 1.221403.

Respuesta: y₂ ≈ 1.220947, con un error de 4.6 × 10−4.
2. ¿Por qué Adams-Moulton se llama implícito?¿Ver ejercicio resuelto?

Su fórmula incluye el término 9fn+1 = 9f(tn+1, yn+1).

Es decir, el valor buscado yn+1 aparece a ambos lados de la igualdad.

Para despejarlo haría falta resolver una ecuación no lineal en cada paso (por ejemplo con Newton).

El esquema predictor-corrector evita ese costo estimando yn+1 con Adams-Bashforth.

Respuesta: Porque la incógnita yn+1 aparece dentro de f en el lado derecho de la fórmula.
3. Cuenta las evaluaciones de f de RK4 y de Adams PECE para 1000 pasos.¿Ver ejercicio resuelto?

RK4: 4 evaluaciones por paso × 1000 = 4000 evaluaciones.

Adams PECE: 2 evaluaciones por paso (una del predictor, una del corrector) × 1000 ≈ 2000, más 12 del arranque con RK4.

Ahorro de aproximadamente el 50 % del trabajo.

Respuesta: RK4: 4000; Adams PECE: unas 2012 — casi la mitad.
4. Con h = 0.2, el predictor da 1.7 y el corrector 1.702. Estima el error local.¿Ver ejercicio resuelto?

La estimación del error local del método de cuarto orden es |yc − yp| · 19/270.

|1.702 − 1.7| = 0.002.

0.002 × 19/270 = 0.002 × 0.0704 = 1.41 × 10−4.

Respuesta: Aproximadamente 1.4 × 10−4; si esa cota supera la tolerancia, hay que reducir h.
