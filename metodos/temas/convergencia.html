Tasas de convergencia y métodos iterativos

La pregunta práctica de todo método iterativo: ¿cuántas iteraciones necesito y por qué unos métodos son tan rápidos frente a otros?

En esta página

Practicar este tema Ver los 16 temas

Idea central

Un método iterativo no resuelve el problema de una vez: construye una sucesión x₀, x₁, x₂, … que se aproxima a la solución. La tasa (u orden) de convergencia responde a la pregunta práctica de todo ingeniero: ¿cuántas iteraciones voy a necesitar?

Error de la iteración n

en = | xn − x* |

Relación asintótica

en+1 ≈ λ · enα

Orden estimado a partir de datos

α ≈ ln(en+2/en+1) / ln(en+1/en)

Clasificación de los métodos del curso

MétodoTipoOrden α¿Necesita derivada?¿Convergencia garantizada?

Regla falsaCerrado1 (lineal)NoSí, si f(a)·f(b) < 0
Punto fijoAbierto1 (lineal, λ = |g′(x*)|)NoSolo si |g′(x)| < 1

Regla general: a mayor orden, menos iteraciones, pero menos garantías. Los métodos cerrados son lentos y seguros; los abiertos, rápidos y arriesgados.

Estrategia híbrida

En la práctica se combinan: se usan unas pocas iteraciones de bisección para acorralar la raíz y luego se cambia a Newton para rematar con convergencia cuadrática. Ese es exactamente el principio del método de Brent, el que trae SciPy por defecto.

Se aproxima √2 resolviendo f(x) = x² − 2 = 0. La bisección arranca en [1, 2] y Newton en x₀ = 2. El valor verdadero es √2 = 1.41421356237.

En la iteración 4 Newton ya tiene más de 10 cifras correctas; la bisección, tras 8 iteraciones, apenas alcanza 3. El exponente del error de Newton se duplica en cada paso: es la firma de la convergencia cuadrática.

Cómo se estima el orden a partir de los datos

Si no conoces el orden teórico, puedes medirlo. Con tres errores consecutivos:

Estimación numérica del orden
import math

def orden(e0, e1, e2):
    return math.log(e2 / e1) / math.log(e1 / e0)

# Errores de Newton para x^2 - 2 = 0 desde x0 = 2
errores = [5.858e-1, 8.579e-2, 2.453e-3, 2.124e-6, 1.595e-12]
for i in range(len(errores) - 2):
    print(f"alpha ~= {orden(errores[i], errores[i+1], errores[i+2]):.3f}")
# Salida: valores que se acercan a 2.000 -> convergencia cuadratica

Si el orden medido no coincide con el teórico, casi siempre hay un error en la implementación: es una de las mejores pruebas de que tu código está bien.

Errores comunes

  • Medir el orden lejos de la raíz. El orden es un resultado asintótico: solo aparece cuando xn ya está cerca de x*.
  • Ignorar el costo por iteración. Newton hace dos evaluaciones (f y f′) por paso; comparar solo el número de iteraciones lo favorece injustamente.
  • Suponer que orden 2 implica que siempre gana. Con una raíz múltiple, Newton degenera a orden 1 y puede ser más lento que la bisección.

Banco de ejercicios propuestos

Aplica la definición en+1 ≈ λ enα en cada caso.

1. Un método produce los errores 0.1, 0.01, 0.001 y 0.0001. ¿Cuál es su orden?¿Ver ejercicio resuelto?

Cada error es la décima parte del anterior: en+1 = 0.1 · en.

Eso corresponde a α = 1 con λ = 0.1.

Gana exactamente una cifra decimal por iteración.

Respuesta: Convergencia lineal (α = 1) con constante asintótica λ = 0.1.
2. Otro método produce 0.1, 0.01, 0.0001 y 10−8. ¿Cuál es su orden?¿Ver ejercicio resuelto?

e₁ = e₀², e₂ = e₁², e₃ = e₂².

El exponente del error se duplica: 1 → 2 → 4 → 8.

Aplicando la fórmula: ln(10−4/10−2)/ln(10−2/10−1) = ln(10−2)/ln(10−1) = 2.

Respuesta: Convergencia cuadrática (α = 2) con λ = 1.
3. ¿Cuántas iteraciones de bisección hacen falta en [1, 2] para un error menor que 10−6?¿Ver ejercicio resuelto?

Tras n iteraciones el error máximo es (b − a)/2n = 1/2n.

Se exige 1/2n < 10−6, o sea 2n > 106.

n > 6 · log₂(10) = 6 × 3.3219 = 19.93.

Respuesta: 20 iteraciones (fórmula general: n > log₂((b−a)/ε)).
4. Para el punto fijo x = g(x) con g(x) = (x + 2/x)/2, calcula g′(√2) e interpreta el resultado.¿Ver ejercicio resuelto?

g′(x) = (1 − 2/x²)/2.

En x = √2: g′(√2) = (1 − 2/2)/2 = 0.

Cuando g′(x*) = 0, la convergencia lineal desaparece y el método pasa a ser cuadrático.

De hecho esta g es exactamente la iteración de Newton para x² − 2 = 0 (el método babilónico).

Respuesta: g′(√2) = 0, por lo que la convergencia es cuadrática, no lineal.
