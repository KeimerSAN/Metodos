Errores de redondeo y aritmética de computadores

Medir, acotar y propagar el error: el vocabulario que convierte un número en información confiable.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Todo resultado numérico viene acompañado de un error. La teoría de errores nos da el vocabulario para medirlo, acotarlo y predecir cómo se propaga a través de los cálculos. Sin ella, un resultado numérico no es información: es solo un número.

Tipos de error

InherenteDatos de entrada medidosUna longitud medida como 2.35 ± 0.01 mSolo mejorando el instrumento

Error absoluto

Ea = | valor verdadero − valor aproximado |

Error relativo

Er = Ea / | valor verdadero |

Error relativo porcentual

ε% = Er × 100 %

Error relativo aproximado

εa = | (xn − xn−1) / xn | × 100 %

¿Absoluto o relativo?

El error absoluto por sí solo engaña. Equivocarse en 1 metro midiendo un lápiz es catastrófico; equivocarse en 1 metro midiendo la distancia Bogotá–Quibdó es irrelevante. El error relativo es el que dice si un resultado sirve.

Cifras significativas

Un valor aproximado tiene n cifras significativas correctas si su error relativo cumple el criterio de Scarborough:

Criterio de Scarborough

εa < (0.5 × 102−n) %

Cifras significativas deseadasTolerancia εa requerida

60.00005 %

Ejercicio resuelto 2: propagación del error

Se mide el lado de un cuadrado como L = 5.00 m con un error absoluto de 0.02 m. ¿Cuál es el error del área A = L²?

Paso 1 — Fórmula de propagación: EA ≈ |dA/dL| · EL = |2L| · EL.

Paso 2 — Sustituir: EA ≈ 2(5.00)(0.02) = 0.20 m².

Paso 3 — Error relativo: A = 25.00 m², luego Er = 0.20/25.00 = 0.8 %.

Conclusión: el error relativo del lado era 0.02/5.00 = 0.4 %, y el del área es exactamente el doble. Al elevar al cuadrado, el error relativo se duplica.

Propagación en una variable

Ef ≈ | f′(x) | · Ex

Propagación en varias variables

Ef ≈ Σ | ∂f/∂xi | · Exi

Número de condición

κ = | x · f′(x) / f(x) |

Si κ es grande, el problema está mal condicionado: un pequeño error en los datos produce un gran error en el resultado, y ningún algoritmo puede arreglarlo. Si κ es pequeño pero el resultado sale mal, el culpable es el algoritmo: se dice que es inestable.

Errores comunes

  • Reportar más cifras de las justificadas. Escribir 3.14285714 cuando solo 3 cifras son correctas transmite una precisión que no existe.
  • Usar el error absoluto para juzgar la calidad. Sin comparar contra la magnitud del valor, el error absoluto no dice nada.
  • Confundir mal condicionamiento con inestabilidad. El condicionamiento es propiedad del problema; la estabilidad, del algoritmo elegido.

Banco de ejercicios propuestos

Calcula siempre los dos errores: el absoluto y el relativo.

1. Se aproxima e = 2.718281828 con 2.71. Calcula error absoluto, relativo y porcentual.¿Ver ejercicio resuelto?

Ea = |2.718281828 − 2.71| = 0.008281828

Er = 0.008281828 / 2.718281828 = 0.003047

ε% = 0.3047 %

Respuesta: Ea = 0.008282, Er = 0.003047, ε% = 0.3047 % (3 cifras significativas).
2. Se mide el radio de un círculo como r = 3.00 cm con error de 0.05 cm. Estima el error del área.¿Ver ejercicio resuelto?

A = πr², luego dA/dr = 2πr.

EA ≈ 2π(3.00)(0.05) = 0.9425 cm².

A = π(9) = 28.27 cm², así que Er = 0.9425/28.27 = 3.33 %.

Coincide con el doble del error relativo del radio (0.05/3.00 = 1.67 %).

Respuesta: EA ≈ 0.94 cm², es decir 3.33 % de error relativo.
3. ¿Qué tolerancia hace falta para garantizar 4 cifras significativas?¿Ver ejercicio resuelto?

Criterio de Scarborough: εa < 0.5 × 102−n %.

Con n = 4: 0.5 × 10−2 % = 0.005 %.

Respuesta: εa < 0.005 %, equivalente a un error relativo de 5 × 10−5.
4. Una serie alternante se trunca en el término n. ¿Cómo se acota el error de truncamiento?¿Ver ejercicio resuelto?

Para una serie alternante convergente cuyos términos decrecen en valor absoluto, el teorema de Leibniz garantiza que el error es menor que el primer término omitido.

Ejemplo: al aproximar e−1 con la serie 1 − 1 + 1/2! − 1/3! + … truncada tras 1/4!, el error es menor que 1/5! = 0.00833.

Respuesta: El error de truncamiento es menor que el valor absoluto del primer término descartado.
