Algoritmos y convergencia

Qué hace que un algoritmo numérico sea confiable: estabilidad frente al redondeo y velocidad medible de convergencia.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Un algoritmo es una secuencia finita, ordenada y no ambigua de operaciones que transforma unos datos de entrada en un resultado. En análisis numérico no basta con que el algoritmo sea correcto: tiene que ser estable (no amplificar los errores de redondeo) y convergente (acercarse realmente a la solución conforme avanza).

Estabilidad de un algoritmo

Si E₀ es el error inicial y En el error tras n operaciones, la forma en que crece el error clasifica al algoritmo:

ComportamientoCrecimiento del errorClasificación
LinealEn ≈ C · n · E₀Estable — aceptable
ExponencialEn ≈ C · kn · E₀ con k > 1Inestable — inutilizable

Un crecimiento lineal del error es inevitable y tolerable. Uno exponencial destruye el resultado en pocas iteraciones, por pequeño que sea E₀.

Condicionamiento frente a estabilidad

El condicionamiento es una propiedad del problema: mide cuánto se amplifica un error de los datos. La estabilidad es una propiedad del algoritmo: mide cuánto error añade él mismo. Un problema mal condicionado no se arregla cambiando de algoritmo.

Orden de convergencia

Si una sucesión {xn} converge a x* y existen constantes λ > 0 y α ≥ 1 tales que:

Definición de orden de convergencia

limn→∞ | xn+1 − x* | / | xn − x* |α = λ

entonces se dice que la sucesión converge con orden α y constante asintótica λ.

Orden αNombreComportamiento del errorMétodo típico
1 (λ < 1)LinealGana un número fijo de cifras por iteraciónBisección, punto fijo
1.618SuperlinealAcelera sin llegar a duplicarSecante
1.84SuperlinealCasi cuadráticoMuller
2CuadráticoDuplica las cifras correctas en cada pasoNewton-Raphson

Un método cuadrático pasa de 3 a 6 y luego a 12 cifras correctas en dos iteraciones; uno lineal necesitaría decenas.

Notación O grande

Se escribe f(h) = O(hp) cuando existe una constante C tal que |f(h)| ≤ C·hp para h suficientemente pequeño. Sirve para comparar métodos sin depender de constantes concretas.

Medir el orden de convergencia experimentalmente
import math

def orden_observado(errores):
    """Estima alpha a partir de tres errores consecutivos."""
    ordenes = []
    for i in range(len(errores) - 2):
        e0, e1, e2 = errores[i], errores[i+1], errores[i+2]
        if e1 > 0 and e0 > 0:
            alpha = math.log(e2 / e1) / math.log(e1 / e0)
            ordenes.append(alpha)
    return ordenes

# Errores de Newton para x^2 - 2 = 0 desde x0 = 2
errores_newton = [5.9e-1, 8.6e-2, 2.5e-3, 2.1e-6, 1.6e-12]
print(orden_observado(errores_newton))   # valores cercanos a 2.0

# Errores de biseccion
errores_bis = [5.0e-1, 2.5e-1, 1.25e-1, 6.25e-2, 3.125e-2]
print(orden_observado(errores_bis))      # valores cercanos a 1.0

02

Simulación

Elegir el orden del integrador decide cuántos pasos se necesitan y, por tanto, el tiempo de cómputo.

03

Optimización

En aprendizaje automático se prefiere un método de orden 1 barato antes que uno de orden 2 costoso por iteración.

Ventajas y desventajas

Ventajas

  • Permite predecir cuántas iteraciones costará alcanzar una tolerancia.
  • Da un criterio objetivo para escoger entre dos métodos.
  • Detecta implementaciones mal programadas: si el orden observado no coincide con el teórico, hay un error en el código.

Desventajas

  • El orden es un resultado asintótico: solo vale cerca de la raíz.
  • Un orden alto no sirve si cada iteración es muy costosa.
  • Newton pierde su orden 2 y baja a orden 1 cuando la raíz es múltiple.

Errores comunes

  • Confundir converger con converger rápido. La bisección siempre converge, pero es de las más lentas: garantía y velocidad son cosas distintas.
  • Comparar métodos por número de iteraciones. Lo justo es comparar por número de evaluaciones de f, porque Newton necesita además f′ en cada paso.
  • Suponer que el orden teórico se cumple desde la primera iteración. Con un x₀ lejano, incluso Newton puede tener varias iteraciones erráticas antes de entrar en régimen cuadrático.

Banco de ejercicios propuestos

Estos ejercicios se resuelven aplicando directamente la definición de orden.

1. Un método lineal con λ = 0.5 parte de un error de 0.1. ¿Cuántas iteraciones necesita para bajar de 10−6?¿Ver ejercicio resuelto?

El error tras n pasos es 0.1 × 0.5n.

Se pide 0.1 × 0.5n < 10−6, es decir 0.5n < 10−5.

n > 5 · log(10)/log(2) = 5 × 3.3219 = 16.61.

Respuesta: 17 iteraciones.
2. Un método cuadrático tiene error 10−2 y λ = 1. ¿Cuáles son los tres errores siguientes?¿Ver ejercicio resuelto?

en+1 ≈ en².

e₁ = (10−2)² = 10−4

e₂ = (10−4)² = 10−8

e₃ = (10−8)² = 10−16

Respuesta: 10−4, 10−8 y 10−16: en tres pasos alcanza el límite de la doble precisión.
3. El error de un método es O(h²). Si con h = 0.1 el error es 0.004, ¿cuánto será con h = 0.025?¿Ver ejercicio resuelto?

h pasa de 0.1 a 0.025: se divide entre 4.

Al ser O(h²), el error se divide entre 4² = 16.

0.004 / 16 = 0.00025.

Respuesta: Aproximadamente 2.5 × 10−4.
