Método de Taylor de orden superior

Conservar más términos de la serie para ganar orden: más precisión a cambio de derivar f una y otra vez.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Si Euler trunca la serie de Taylor en el término lineal, la pregunta natural es: ¿y si conservamos más términos? Eso es exactamente el método de Taylor de orden n: se desarrolla y(t + h) en serie de Taylor y se conservan los términos hasta hn.

El precio es que hay que calcular las derivadas totales sucesivas de f(t, y), lo cual se vuelve tedioso rápidamente. Esa incomodidad es precisamente la que motivó la aparición de los métodos de Runge-Kutta, que alcanzan el mismo orden sin derivar.

El problema de valor inicial que usaremos en toda la unidad

y′ = y − t² + 1, con y(0) = 0.5 en el intervalo [0, 2] y paso h = 0.2. Su solución exacta es y(t) = (t + 1)² − ½et, así que podemos comparar el error real de cada método sobre exactamente el mismo problema.

Desarrollo de Taylor de la solución

y(t+h) = y(t) + h y′(t) + (h²/2!) y″(t) + … + (hn/n!) y(n)(t)

Método de Taylor de orden n

yn+1 = yn + h · T(n)(tn, yn)

Función incremento

T(n) = f + (h/2)f′ + (h²/6)f″ + … + (hn−1/n!)f(n−1)

Error local / global

O(hn+1) por paso  →  O(hn) acumulado

Ojo con la derivada: es total, no parcial

Como y depende de t, la derivada de f respecto de t debe aplicar la regla de la cadena: f′ = ∂f/∂t + (∂f/∂y)·f. Olvidar el segundo sumando es el error más frecuente de este tema.

Cálculo de las derivadas para nuestro problema

Con f(t, y) = y − t² + 1 se tiene ∂f/∂t = −2t y ∂f/∂y = 1, luego:

DerivadaDesarrolloExpresión final
f—y − t² + 1
f′∂f/∂t + (∂f/∂y)·f = −2t + (1)(y − t² + 1)y − t² − 2t + 1
f″derivando de nuevo por la cadenay − t² − 2t − 1
f⁈derivando una vez másy − t² − 2t − 1

Para este problema las derivadas se estabilizan a partir del orden 2, lo que facilita construir Taylor de orden 3 o 4.

Algoritmo (Taylor de orden 2)

  1. Obtener analíticamente f′ = ∂f/∂t + (∂f/∂y)·f.
  2. Fijar h, t₀ e y₀.
  3. En cada paso, evaluar f(tn, yn) y f′(tn, yn).
  4. Aplicar yn+1 = yn + h·f + (h²/2)·f′.
  5. Avanzar tn+1 = tn + h y repetir.

Con el mismo h y el mismo número de evaluaciones de punto, el orden 2 reduce el error en más de un orden de magnitud.

Taylor de orden 2 en Python
import math

def taylor2(f, df, t0, y0, h, n):
    """df debe ser la derivada TOTAL: df/dt + (df/dy)*f."""
    ts, ys = [t0], [y0]
    t, y = t0, y0
    for _ in range(n):
        y = y + h * f(t, y) + (h**2 / 2) * df(t, y)
        t = t + h
        ts.append(t)
        ys.append(y)
    return ts, ys


f  = lambda t, y: y - t**2 + 1
df = lambda t, y: y - t**2 - 2*t + 1        # derivada total
exacta = lambda t: (t + 1)**2 - 0.5 * math.exp(t)

ts, ys = taylor2(f, df, 0.0, 0.5, 0.2, 10)
for t, y in zip(ts, ys):
    print(f"{t:.1f}  {y:.7f}  error={abs(exacta(t)-y):.7f}")

Ventajas y desventajas

Ventajas

  • Alcanza el orden que se desee: basta con derivar más veces.
  • Con el mismo paso h, un Taylor de orden 2 ya es muchísimo más preciso que Euler.
  • Su análisis de error es directo: sale del residuo de la serie de Taylor.
  • Es el marco teórico con el que se demuestra el orden de los métodos de Runge-Kutta.

Desventajas

  • Exige calcular a mano las derivadas totales sucesivas de f.
  • Para f complicadas, esas derivadas se vuelven enormes o imposibles.
  • El código deja de ser genérico: hay que reprogramarlo para cada ecuación.
  • Por eso, en la práctica, se prefiere Runge-Kutta, que logra el mismo orden sin derivar.

Aplicaciones típicas en ingeniería

01

Mecánica celeste

Los propagadores de órbitas usan series de Taylor de orden alto cuando se necesita muchísima precisión.

02

Aritmética de intervalos

Los métodos de Taylor permiten acotar rigurosamente el error, algo útil en cálculo verificado.

03

Diferenciación automática

Las bibliotecas modernas generan las derivadas totales por software, devolviendo utilidad práctica a este método.

Errores comunes

  • Usar la derivada parcial en lugar de la total. Escribir f′ = ∂f/∂t olvida el término (∂f/∂y)·f y arruina el orden del método.
  • Equivocar el factorial. El término de orden k lleva hk/k!, no hk/k.
  • Creer que más orden siempre compensa. Si f es cara de evaluar o de derivar, un Runge-Kutta de orden 4 sale mucho más barato que un Taylor de orden 4.

Banco de ejercicios propuestos

Recuerda: la derivada de f es total, con regla de la cadena.

1. Para y′ = t + y, obtén f′ y aplica Taylor 2 con y(0) = 1, h = 0.1.¿Ver ejercicio resuelto?

f(t,y) = t + y → ∂f/∂t = 1, ∂f/∂y = 1.

f′ = 1 + (1)(t + y) = 1 + t + y.

y₁ = 1 + 0.1(0+1) + (0.01/2)(1+0+1) = 1 + 0.1 + 0.01 = 1.11

y₂ = 1.11 + 0.1(0.1+1.11) + 0.005(1+0.1+1.11) = 1.11 + 0.121 + 0.011050 = 1.242050

El valor exacto en t = 0.2 es 2e0.2 − 1.2 = 1.242806.

Respuesta: y₁ = 1.11, y₂ = 1.24205 (error de solo 7.6 × 10−4 frente a 0.0228 de Euler).
2. Para y′ = y, escribe el método de Taylor de orden 3.¿Ver ejercicio resuelto?

f = y, f′ = y, f″ = y: todas las derivadas coinciden.

yn+1 = yn + h yn + (h²/2) yn + (h³/6) yn

= yn(1 + h + h²/2 + h³/6).

El factor entre paréntesis es exactamente la serie de eh truncada en el término cúbico.

Respuesta: yn+1 = yn(1 + h + h²/2 + h³/6)
3. ¿Qué orden de Taylor hace falta para igualar la precisión de Runge-Kutta clásico?¿Ver ejercicio resuelto?

Runge-Kutta de cuatro etapas tiene error global O(h⁴).

Un método de Taylor de orden n tiene error global O(hn).

Hace falta n = 4, lo que obliga a calcular f′, f″ y f⁈ a mano.

Runge-Kutta consigue lo mismo con cuatro evaluaciones de f y ninguna derivada.

Respuesta: Taylor de orden 4 — y esa es justamente la razón de ser de Runge-Kutta.
