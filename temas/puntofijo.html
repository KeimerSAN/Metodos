Inicio/Temas/Punto fijo

Iteración de punto fijo

Reescribe f(x) = 0 como x = g(x) y deja que la propia función, aplicada una y otra vez, converja hacia la solución.

En esta página

Practicar este tema Ver los 16 temas

Idea central

Dada f(x) = 0, se despeja x para obtener una forma equivalente x = g(x). Partiendo de un valor inicial x₀, se genera la sucesión x₍ₙ₊₁₎ = g(xₙ). Si la sucesión converge, lo hace hacia un punto fijo x* que cumple g(x*) = x* — y ese x* es también raíz de la f(x) original.

Es un método abierto: no necesita un intervalo con cambio de signo, solo un valor inicial. Su gran ventaja es la simplicidad; su gran riesgo es que no toda forma de despejar x converge. La condición local de convergencia es |g'(x)| < 1 en la vecindad de la raíz — si no se cumple, hay que despejar x de otra manera.

Diagrama de telaraña: se rebota entre la curva g(x) y la recta y=x. Cada "escalón" es una iteración, acercándose al punto fijo x*.

Algoritmo

  1. Despejar x = g(x) a partir de f(x) = 0.
  2. Verificar que |g'(x)| < 1 cerca del valor inicial x₀ (condición de convergencia local).
  3. Calcular x₁ = g(x₀), x₂ = g(x₁), y así sucesivamente.
  4. En cada paso medir el error |x₍ₙ₊₁₎ − xₙ|.
  5. Detener cuando el error sea menor que ε; si la sucesión diverge, elegir otra forma de g(x).

Ventajas, desventajas y cuándo usarlo

Ventajas

  • Muy simple de programar: solo evalúas g(x) una y otra vez.
  • No necesita un intervalo con cambio de signo, solo un valor inicial.
  • Fácil de visualizar gráficamente como la intersección de y=x con y=g(x).

Desventajas

  • No siempre converge; depende totalmente de qué tan buena sea la g(x) elegida.
  • Cuando converge, suele ser más lento que Muller o Newton-Raphson.
  • Una misma ecuación puede tener varias formas de g(x): unas convergen y otras no, y hay que probarlas.

Algoritmos iterativos

Es la base conceptual de muchos algoritmos de optimización y machine learning que "iteran hasta converger".

Errores comunes al aplicar punto fijo

  • No verificar |g'(x)| < 1 antes de iterar. Si esta condición no se cumple cerca de la raíz, la sucesión puede diverger sin que sea evidente hasta después de varias iteraciones.
  • Elegir la primera g(x) que aparece al despejar x, sin comparar con otras formas posibles que podrían converger más rápido (o converger, cuando la primera no lo hace).
  • Confundir "oscila" con "converge lento". Si los valores van y vienen alrededor de la raíz sin acercarse, probablemente |g'(x)| > 1 y el método está divergiendo, no solo siendo lento.

Banco de ejercicios propuestos

Intenta resolver cada ejercicio tú mismo primero. Cuando quieras comparar, presiona el botón "¿Ver ejercicio resuelto?" y se desplegará la solución explicada paso a paso.

1. f(x) = x² − x − 2, con x = g(x) = √(x + 2), x₀ = 1.5¿Ver ejercicio resuelto?

Paso 1: se evalúa x₁ = g(1.5) = √3.5 ≈ 1.8708.

Paso 2: se sigue iterando x₂ = g(x₁), x₃ = g(x₂)… y la sucesión se acerca cada vez más a 2.

Paso 3: se comprueba: g(2) = √(2+2) = √4 = 2, así que x = 2 es efectivamente el punto fijo.

Respuesta: x = 2
2. La misma ecuación con x = g(x) = x² − 2: ¿por qué diverge?¿Ver ejercicio resuelto?

Paso 1: se calcula la derivada g'(x) = 2x.

Paso 2: se evalúa cerca de la raíz x = 2: g'(2) = 4.

Paso 3: como |g'(2)| = 4 > 1, no se cumple la condición de convergencia local, así que la sucesión se aleja de la raíz en vez de acercarse.

Respuesta: diverge porque |g'(2)| = 4 > 1
3. Encuentra una g(x) convergente para f(x) = cos(x) − x¿Ver ejercicio resuelto?

Paso 1: de f(x) = cos(x) − x = 0 se despeja directamente x = cos(x), es decir g(x) = cos(x).

Paso 2: como |g'(x)| = |−sen(x)| < 1 para casi cualquier x cercano a la raíz, esta forma sí converge.

Paso 3: iterando desde cualquier x₀ razonable (por ejemplo x₀ = 0.5), la sucesión converge al llamado "número de Dottie".

Respuesta: x* ≈ 0.7391 (número de Dottie)
